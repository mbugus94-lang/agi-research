## Research synthesis

The two-week scan shows a consistent architecture direction: long-horizon agents need explicit memory/context management, executable verification, persistent workspaces, and reviewable self-improvement rather than unconstrained autonomy.

- **AgentOmnia** (arXiv:2607.23124) combines task-space definition, environment/tool synthesis, verifiers, evaluation, rollback curricula, and PRD-guided improvement. The useful local pattern is evidence-backed iteration with rollback boundaries.
- **Σ-Mem** (arXiv:2607.27958) makes peer competence and peer relationships updateable reliability memory. This supports retaining source, snapshot, and line provenance instead of collapsing evidence into one score.
- **Skill Self-Play** (arXiv:2607.22529) co-evolves tasks, solvers, and skills with execution feedback. It reinforces that capability growth should be tied to verifiable outcomes.
- **SearchArt** (arXiv:2607.24850) trains long-horizon search using synthetic but verified tasks and evidence-aware trajectory checks. The local analogue is deterministic, replayable review evidence.
- **Agent Team Work Zone** (arXiv:2607.22917) treats persistent filesystem state as recovery infrastructure for long-lived agent teams. This aligns with keeping raw audit envelopes available for replay after compaction or handoff.
- **CORVUS** (arXiv:2607.22711) reduces stale context by synchronizing relevant file state instead of replaying obsolete observations. The same principle applies here: derive both operator surfaces from one current projection rather than duplicating counting logic.
- **Stress-testing LLM agents in a robotic chemistry laboratory** (arXiv:2607.23045) reports a large gap between plausible plans and executable workflows, reinforcing the repository's bounded, review-only posture.

Open-source activity signals included `NousResearch/hermes-agent` (large, active general-purpose agent), `NVIDIA-NeMo/labs-OO-Agents` (modular strategies, memory, tracing, sandboxing, and tests), `MunasheChitima/findandseek-engine` (local-first agent memory exposed through MCP; BUSL-1.1), and `Wiseair-srl/orpc-agent` (typed capabilities, approvals, redaction, and audit). These are activity signals, not a controlled popularity ranking.
